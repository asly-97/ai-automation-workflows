# Notion content queue schema

| Property | Type | Notes |
|---|---|---|
| Target question | Title | The exact question people ask, e.g. "Does X remember between sessions?" |
| Status | Select | Queued, Awaiting review, Published, Skipped |
| Live URL | URL | Filled by the publish agent |
| Published | Date | Filled by the publish agent |
| Skip reason | Text | Filled when the draft agent skips a row as a duplicate |

Keep the queue to real questions. If you can't point to someone actually asking it, it doesn't go in.
